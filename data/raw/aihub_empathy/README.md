# AI Hub 공감형 대화 (수동)

이 폴더는 **수동 다운로드**용입니다.

1. https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71305 접속
2. 로그인 후 데이터 신청·다운로드
3. 압축을 이 디렉터리에 해제

예상 라벨 (연구 축 매핑):
- 공감 전략 → **S**: 조언 / 격려 / 위로 / 동조
- 관계 → **R**
- 감정/상황 → **A / C** (스키마 확인 후 매핑)

해제 후 예:
```
data/raw/aihub_empathy/
  README.md          # this file
  ...json / tsv...
```
